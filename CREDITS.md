# Credits

## Ideas from other mods

- **[Simple-Declutter](https://github.com/gitTerebi/Simple-Declutter)** by gitTerebi. The *Declutter small objects* and *Declutter medium objects* settings are based on its idea of hiding small decorative clutter. SPT-Optimizer's version is a separate implementation for SPT 4.x: no code was copied, and it uses its own rules. Only renderers are hidden, never colliders, so everything stays solid; objects with a trigger, sound, light or game script are skipped, and EFT's projected decals are never touched.
